# forticnapp_toolbox

A collection of scripts to simplify everyday FortiCNAPP and cloud security tasks.

## AWS tools

| Script | Description |
|---|---|
| `create_user_sts.sh` | Creates an IAM user and an administrator role, generates user access keys, and configures AWS CLI profiles to assume the role using temporary STS credentials. |
| `delete_user_sts.sh` | Removes the IAM user and role created by the setup script, along with their associated keys and policies. |

### Prerequisites

Run the scripts in Bash from either:

- **AWS CloudShell:** Open CloudShell from the AWS Management Console. The AWS CLI is preinstalled and uses your signed-in identity.
- **Your own host:** Install the AWS CLI and authenticate to your AWS account before running the scripts.

Your active AWS identity must have permission to create and delete IAM users, roles, policies, and access keys. Run the scripts from the folder containing them.

### How to use

**Create the user and role:**

```bash
chmod +x create_user_sts.sh
./create_user_sts.sh
```

When prompted, enter the access key ID and secret generated by the script.

**Delete the resources when finished:**

```bash
chmod +x delete_user_sts.sh
./delete_user_sts.sh
```

Use your original administrator credentials for cleanup.

> **Security:** The setup grants administrator access through a role. Protect the user’s long-term access keys and delete the resources when no longer needed.
