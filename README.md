# forticnapp_toolbox

A collection of scripts to simplify everyday FortiCNAPP and cloud security tasks.

## AWS tools

Use these scripts to prepare administrator access for integrating FortiCNAPP with AWS. The setup creates an IAM user and a role that the user can assume through AWS STS to obtain a temporary access key, secret access key, and session token.

After the integration is complete, run the cleanup script to remove the temporary setup’s IAM user, access keys, policies, and role.

> **Note:** The IAM user’s access keys are long-lived. Only the credentials issued by STS are temporary.

| Script | Description |
|---|---|
| `create_user_sts.sh` | Creates an IAM user and administrator role, generates user access keys, and configures AWS CLI profiles to assume the role. |
| `delete_user_sts.sh` | Removes the IAM user and role created by the setup script, along with their associated keys and policies. |
| `tf_inventory.sh`    | Removes the IAM user and role created by the setup script, along with their associated keys and policies. |

### Prerequisites

Run the scripts in Bash from either:

- **AWS CloudShell:** Open CloudShell from the AWS Management Console. The AWS CLI is preinstalled and uses your signed-in identity.
- **Your own host:** Install the AWS CLI and authenticate to your AWS account before running the scripts.

Your active AWS identity must have permission to manage IAM users, roles, policies, and access keys. Run the scripts from the folder containing them.

### How to use

**Create the user and role:**

```bash
chmod +x create_user_sts.sh
./create_user_sts.sh
```

When prompted, enter the access key ID and secret generated by the script.

**Retrieve temporary credentials for the integration:**

```bash
aws sts assume-role \
  --profile sts-admin-user \
  --role-arn "arn:aws:iam::<ACCOUNT_ID>:role/AssumableAdminRole" \
  --role-session-name FortiCNAPPIntegration
```

Replace `<ACCOUNT_ID>` with your AWS account ID. The response contains `AccessKeyId`, `SecretAccessKey`, `SessionToken`, and `Expiration`.

**Clean up after integration:**

Using your original administrator credentials, run:

```bash
chmod +x delete_user_sts.sh
./delete_user_sts.sh
```

Remove only the setup resources; retain the roles and resources required by the FortiCNAPP integration.

**TF Inventory integration:**

Using your original administrator credentials, run:

```bash
chmod +x tf_inventory.sh
./tf_inventory.sh
```
